# Steam Games Search Engine - CS-250 DSA Semester Project (BESE-2025)

## Project structure

- `backend/tokenizer` — shared tokenizer
- `backend/indexer` — lexicon, forward index, inverted index, barrels
- `backend/search` — BM25, multi-word, semantic search, autocomplete
- `backend/app` — FastAPI
- `frontend` — React + Vite
- `data/test` — 1,000-game test file
